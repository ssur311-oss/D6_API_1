# API 화면 규칙

## 규칙
- 키가 필요 없는 공개 API만 쓴다. 주소에 `key=`, `token=`, `apikey=`가 필요하거나 문서에 Authentication이 있으면 만들지 말고 "이 API는 키가 필요해서 D8 방식이 필요해요"라고 알려 준다. (왜: HTML은 누구나 코드를 볼 수 있어서 키가 새어 나감)
- API 주소는 파일 맨 위 `<head>` 의 `<script>` 안 `const API = { ... }` 한 곳에 모으고, 각 줄에 `// 🔌` 주석을 단다. `fetch` 하는 줄에도 `// 🔌 API 호출` 주석을 단다. (왜: 어디가 API인지 바로 찾으려고)
- 화면 맨 아래에 "🔌 이 화면이 쓰는 API" 상자를 두고, 실제로 부른 주소와 "새 탭에서 원본 JSON 보기" 링크를 보여 준다. (왜: 주소를 바꾸면 주문이 바뀌는 걸 눈으로 보려고)
- 카드마다 **로딩 중** 문구와 **불러오기 실패** 화면(+ 다시 시도)을 넣는다. 한 카드가 실패해도 다른 카드는 보이게 따로 부른다. (왜: 무료 API는 멈추거나 바뀜)
- 화면에 **데이터 출처**를 적는다. Open-Meteo는 "Weather data by Open-Meteo.com". (왜: API 규칙이 출처 표기를 요청함)
- 날짜가 있는 데이터는 **기준 날짜/시각**을 함께 보여 준다. API 문서가 실시간이라고 하지 않으면 "실시간"이라고 쓰지 않는다. (왜: 환율은 하루 한 번 발표되는 기준값)
- HTML 파일 하나에 CSS와 JavaScript를 함께 넣는다. 외부 파일·라이브러리 없이 더블클릭으로 열려야 한다. (왜: 설치 없이 바로 확인하려고)

## API별로 알아낸 것 (실제 응답으로 확인함)
- **Open-Meteo 지오코딩** (`geocoding-api.open-meteo.com/v1/search`): 짧은 한국어 이름은 결과가 없거나 엉뚱한 마을이 나온다("서울" → 0건, "부산" → 경북 마을 Pusan, "수원" → 전북 마을). "서울특별시", "부산광역시", "수원시"나 영어 이름은 잘 된다. 그래서 `count=10`으로 받아 `population`이 가장 큰 후보를 고르고 나머지는 선택지로 보여 준다.
- **Open-Meteo 예보/대기질**: `current=` 값은 15분(날씨)·1시간(대기질) 간격 값이다. 대기질은 모델 값이라 에어코리아 측정소 값과 다를 수 있다고 안내한다. 미세먼지 등급은 환경부 기준: PM10 좋음 ≤30 / 보통 ≤80 / 나쁨 ≤150 / 매우 나쁨, PM2.5 ≤15 / ≤35 / ≤75 / 매우 나쁨.
- **Frankfurter** (`api.frankfurter.dev/v1/latest`): 유럽중앙은행 기준 환율, 영업일 하루 한 번. 응답의 `date`를 기준 날짜로 보여 준다. `base=USD&symbols=KRW,JPY` 한 번으로 100엔 = `KRW / JPY × 100`을 계산할 수 있다.
- **Nager.Date** (`date.nager.at/api/v3/NextPublicHolidays/KR`): 이름은 `localName`(한국어)을 쓰고 없으면 `name`. 주소가 틀리면 404가 아니라 500을 돌려줄 수 있으니 `res.ok`로 판단한다.
- **Dog CEO** (`dog.ceo/api/breeds/image/random`): `message`가 사진 주소다. 견종은 주소의 `/breeds/<견종>/`에서 꺼낸다. 사진 파일 자체가 안 열릴 때를 위해 `<img onerror>`도 처리한다.
